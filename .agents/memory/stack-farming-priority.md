---
name: Stack Farming priority rules
description: User-defined scheduling for Stack Farming jobs alongside Main Farming.
---

Stack Farming may interrupt Main Farming and resume it after completion, but must wait for any active task-owned travel or future feature task to finish. User-started Travel-tab trips are low-priority background work like Main Farming and may be interrupted by Stack Farming; travel initiated on behalf of another task keeps that task's priority. Stack jobs preserve FIFO order; within a consecutive batch of fruit tasks, order pickups by the shortest gateway-aware route. Enabled Stack Farming tasks also run when Main Farming is off, provided no other foreground task owns the worker. Boss preparation is a queued stack job: only prepare when the user already holds the required summon item, and do not let later jobs overtake a preparation already in progress. A held God's Chalice with both Indra and Dough King enabled reserves Stack priority while Haki ownership is checked; server hopping must not leapfrog that choice. If Haki ownership cannot be verified after bounded retries, don't guess a boss or risk consuming the chalice; require an explicit Indra/Dough King priority. Indra/Dough priority toggles require their parent boss toggle and are mutually exclusive. Elite and berry hop toggles require their corresponding local parent task. Server-hop jobs wait behind active and earlier queued Stack Farming jobs. Chest farming belongs in Farming Other, not Stack Farming, because it is continuous and conflicts with other farming.

Enabled-but-idle Stack toggles must not hold a coordinator lease or block ordinary Travel. Only an active spawned job, valid summon preparation, or hop owns Stack priority; if one is active, reject Travel immediately, turn its toggle back off, and explain which task must finish.

**Why:** The user clarified that Stack Farming should preempt only Main Farming. Other current or future features must finish their active task before a stack job starts; module-specific priority checks would make this fragile as tabs are added. An unavailable Haki ownership response is not evidence that the player lacks colors, and guessing could waste a rare God's Chalice.

**How to apply:** Use a shared task coordinator for Stack Farming, manual Travel-tab trips, and future task-based tabs. Give manual travel and Main Farming low-priority leases; task-owned movement uses the owning task's lease. Defer Stack work behind active task-owned work, but allow Stack to preempt low-priority work. Keep Stack jobs FIFO, optimize fruit batches internally without moving them ahead of an earlier non-fruit job, and reuse shared movement/combat services.
