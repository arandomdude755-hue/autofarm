GitHub `dev` is the test version of the hub; `main` is the main version.

**Why:** the user explicitly defined this branch split.

**How to apply:** Keep `dev` as the test branch and `main` as the main version when pushing or promoting code. Leave the other branch untouched when asked to update one.
