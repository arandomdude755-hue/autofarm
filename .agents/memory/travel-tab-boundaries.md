---
name: Travel tab boundaries
description: User-approved scope for manual island and NPC travel.
---

Manual travel is a one-shot action with an explicit cancel control. Offer only destinations in the current sea; the player changes seas manually. Do not add automatic sea travel or server hopping. Travel and Auto Farm must not move the character at the same time.

**Why:** the user chose a one-shot travel action, manual sea changes, no server hopping, and no movement conflict with Auto Farm.

**How to apply:** keep destination lists current-sea-filtered, reject travel while Auto Farm is active, and cancel travel before Auto Farm starts.
